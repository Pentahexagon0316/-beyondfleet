# BeyondFleet Product Restructure Plan

작성일: 2026-05-10
역할: CTO 제품/기술 점검
목표: BeyondFleet을 "귀여운 크립토 커뮤니티"에서 "한국어 크립토 교육 + 시장 인텔리전스 플랫폼"으로 재정렬한다.

## 1. 포지셔닝

BeyondFleet의 1차 고객은 암호화폐를 배우고 싶지만 정보 과부하, 사기성 콘텐츠, 과장된 리딩방에 피로한 한국어 사용자다.

핵심 약속:

- 매일 시장에서 봐야 할 정보만 정리한다.
- 초보자가 위험을 이해하면서 단계별로 배운다.
- 데이터, 출처, 리스크 고지를 함께 제공한다.
- 투자 조언이 아니라 학습과 의사결정 보조 정보로 제공한다.

## 2. 정보 구조

첫 화면에서 보여줄 순서:

1. Market Brief: 오늘의 핵심 시장 변화, 리스크, 주요 이벤트
2. Learning Path: 초급, 중급, 고급 교육 경로
3. Market Data: 가격, 뉴스, 고래/기관 신호로 이동
4. Membership: 무료 요약과 프리미엄 분석의 차이
5. Trust Layer: 면책, 출처, 보안, 데이터 기준

주요 라우트 역할:

- `/`: 제품 설명이 아니라 바로 브리핑/교육 입구를 보여주는 운영 화면
- `/cosmic-radar`: AI Daily Brief와 시장 시그널의 핵심 상품
- `/learn`: 단계별 교육 커리큘럼
- `/news`: 필터링된 뉴스와 프리미엄 인사이트
- `/prices`: 실시간 시세와 관심 목록 유입
- `/membership`: 유료 전환 설명
- `/nft`: 추후 멤버십 소유권/리워드 영역으로 축소

## 3. 디자인 원칙

- Comic/Gaegu 폰트, 과한 이모지, 랜덤박스식 긴박감은 핵심 화면에서 제거한다.
- 다크 UI는 유지하되 금융/리서치 툴처럼 조용하고 밀도 있게 만든다.
- CTA는 "시세 확인"보다 "오늘 브리핑 보기", "학습 시작"처럼 정보 가치 중심으로 둔다.
- 캐릭터 Otty는 보조 브랜드 자산으로만 사용하고, 첫 화면 주인공으로 쓰지 않는다.
- 모든 프리미엄 유도는 잠금보다 "무엇을 더 볼 수 있는지"를 먼저 설명한다.

## 4. 1차 구현 범위

- 홈 화면을 시장 브리핑 + 교육 경로 중심으로 재구성
- 헤더 내비게이션에서 NFT/랜덤박스를 전면에서 내리고, 브리핑/교육/뉴스/시세를 전면으로 올림
- 푸터 카피를 신뢰, 교육, 면책 중심으로 수정
- 기존 기능 라우트는 유지하되 고객이 보는 우선순위를 바꿈

## 5. 다음 단계

- CSRF fetch helper를 만들고 POST/PUT 호출에 적용
- 지갑 로그인은 단순 연결 성공이 아니라 nonce 서명 검증 흐름으로 연결
- NFT 구매/입찰은 실제 서명 트랜잭션 전까지 beta/disabled 처리
- `/learn`에 퀴즈, 체크리스트, 학습 완료 기준 추가
- Daily Brief에 출처, 데이터 시각화, 리스크 태그 추가
- Vercel Analytics/Sentry로 가입 전환, 브리핑 열람, 학습 완료율 측정
